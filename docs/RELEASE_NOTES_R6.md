# Release r6 — passagem para o ERP real

Esta release acompanha o Capítulo 13 da primeira edição do livro.

- adiciona um starter neutro, separado do TechStore;
- inclui servidor MCP 2026-07-28 por stdio;
- implementa `server/discover`, `tools/list` e `tools/call`;
- disponibiliza a tool `consultar_produto` com argumento `id`;
- inclui demonstração VCL usando o mesmo contrato do servidor;
- adiciona testes diretos, de protocolo, processo e UTF-8;
- documenta a extração completa de um evento VCL para serviço reutilizável.

Todos os projetos foram compilados com Delphi 13 Florence Win64, compiler version 37.0.
